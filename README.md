> **Product Mind AI** is a complete, production-grade, frontend-only SaaS application designed for modern product teams, engineering leaders, and founders. It bridges the gap between raw customer feedback and strategic execution by combining **simulated AI text intelligence**, **exact mathematical priority scoring**, **What-If sandbox simulations**, **13-section PRD generation**, **roadmap planning**, and **gated release governance** into an interconnected, enterprise-class workspace.

Features are ranked on a continuous **1.0 to 10.0 scale** governed by the exact 4-factor weighted formula:

$$\text{Priority Score} = (0.35 \times \text{Customer Impact}) + (0.30 \times \text{Urgency}) + (0.20 \times \text{Demand}) + (0.15 \times \text{Business Value})$$

- **Interactive Sliders**: Modify any factor in real-time to watch scores, badges, and rankings re-order immediately.
- **Ranking Tiers**: Automatically classified into *Critical Priority* (8.5–10.0), *High Priority* (7.0–8.49), *Medium Priority* (5.0–6.99), and *Low Priority* (<5.0).

## 📐 Scoring Formula & Data Mechanics

Product Mind AI uses an explicit, deterministic prioritization formula grounded in industry best practices:

```javascript
// Exact factor weights
const FACTOR_WEIGHTS = {
  customerImpact: 0.35, // 35% Customer Reach & Experience
  urgency:        0.30, // 30% Market & Triage Urgency
  demand:         0.20, // 20% Customer Request Volume
  businessValue:  0.15, // 15% Revenue & Strategic Alignment
};

function calculatePriorityScore({ customerImpact, urgency, demand, businessValue }) {
  const score = (0.35 * customerImpact) +
                (0.30 * urgency) +
                (0.20 * demand) +
                (0.15 * businessValue);
  return Math.round(score * 100) / 100; // Returns 1.00 - 10.00
}
```

## 🔒 Zero-Backend Architecture & Confidentiality

- **100% Client-Side Execution**: All NLP classification, sentiment analysis, scoring algorithms, PRD generation, and data transformations run locally in the user's browser.
- **No External Paid APIs**: Strictly zero reliance on OpenAI, Anthropic, Gemini, or third-party paid keys. No credit card or API tokens required.
- **Zero Database Server Footprint**: Utilizes structured browser `localStorage` with error recovery, schema versioning, and JSON backup export/import.
- **Static Hosting Ready**: Built using relative paths (`base: './'`) and `HashRouter` for zero-configuration deployment on **GitHub Pages**, Vercel, Netlify, or any static file host.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.x, v20.x, or later)
- `npm` (v9.x or later)

### Installation & Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/product-mind-ai.git
   cd product-mind-ai
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173`.

4. **Run the automated test suite:**
   ```bash
   npm test
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
   The compiled assets will be placed in the `dist/` directory, ready for immediate static hosting.
